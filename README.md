# 💱 BYN Currency Rates Telegram Bot

Telegram-бот для быстрого получения актуальных курсов валют (USD, EUR, RUB) по отношению к белорусскому рублю (BYN) напрямую от **Национального банка Республики Беларусь (НБРБ)**.

Бот оптимизирован для легкого деплоя на бесплатные хостинги (например, Render.com), так как имеет встроенный веб-сервер для прохождения проверок доступности (Health Checks).

---

## ✨ Особенности

* **Официальные данные:** Курсы берутся напрямую через API НБРБ.
* **Автоматическое обновление:** Кнопка «🔄 Обновить» позволяет актуализировать данные прямо в чате без спама новыми сообщениями.
* **Специфика региона:** Бот показывает точное время запроса по часовому поясу Минска (UTC+3).
* **Готов к деплою (Cloud Ready):** Встроенный HTTP-сервер на выбранном порту отвечает `OK` по пути `/health`, чтобы хостинг не «усыплял» бота.
* **Отказоустойчивость:** Бот умеет сам обрабатывать конфликты подключений (Conflict) и ограничения Telegram API (RetryAfter).

---

## 🛠️ Команды бота

* `/start` — Приветственное сообщение и кнопка для получения курсов.
* `/rate` — Быстрый вывод актуального курса валют.

## 🚀 Быстрый старт (Локальный запуск)

### 1. Клонирование репозитория
```bash
git clone https://github.com
cd название_репозитория
```

### 2. Установка зависимостей
Убедитесь, что у вас установлен Python 3.10+. Установите необходимые библиотеки:
```bash
pip install python-telegram-bot requests pytz
```

### 3. Настройка переменных окружения
Бот требует две важные переменные для работы.

**На Linux / macOS:**
```bash
export TG_TOKEN="ваш_токен_от_BotFather"
export PORT="10000"
```

**На Windows (Command Prompt):**
```cmd
set TG_TOKEN=ваш_токен_от_BotFather
set PORT=10000
```

### 4. Запуск
```bash
python main.py
```

## ☁️ Деплой на Render.com

Этот бот идеально подходит для бесплатного размещения на **Render**. Вот как его настроить:

1. Создайте новый **Web Service** на Render и подключите свой GitHub репозиторий.
2. В настройках укажите:
   * **Language:** `Python`
   * **Start Command:** `python main.py` (или имя вашего файла)
3. Перейдите во вкладку **Environment** и добавьте две переменные:
   * `TG_TOKEN` — токен вашего бота.
   * `PORT` — укажите `10000` (Render автоматически свяжет его со своим прокси).
4. *(Опционально)* В разделе **Advanced** добавьте **Health Check Path**: `/health`. Это покажет Render, что бот успешно запустился и работает.
5. Нажмите **Save Changes**.
